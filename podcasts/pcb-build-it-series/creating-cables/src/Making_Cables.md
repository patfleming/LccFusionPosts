> **Step 3: Expose the wires ** 
> Score only the **outer jacket**, not the wires.  
> Twist, separate, and slide the jacket off cleanly.

(voice: Matt )
Now place about 2.5 inches of the cable into the cable-prep tool
and clamp down gently.  
The tool is designed to score the outer jacket—**not** the wires inside.

(pause: 0.6)

(voice: Matt )
Rotate the cable a few times to make a clean, even score
all the way around the jacket.

(pause: 0.6)

(voice: Matt )
Then remove the cable from the tool, pull gently on the jacket
to separate it, and slide it off the end of the cable.

(pause: 0.8)

(voice: Matt )
If any internal conductor was nicked during this step,
it might work temporarily, but it will almost certainly fail later.

> **Step 5: Prepare the wires**  
> Separate the twisted pairs.  
> Untwist and straighten each conductor.  
> Use a small screwdriver to help remove kinks.  
> Prep **both ends** of the cable now.

(voice: Kirk )
Okay, now we’re looking at the eight wires inside the cable.
This part always looks a little chaotic.

(pause: 0.6)

(voice: Matt )
That’s normal.  
Start by cutting the string off, then separating the four twisted pairs.
Gently spread them apart so you can work with each pair individually.

(pause-until: 15)

(voice: Kirk )
Those twists are pretty tight. Is that intentional?

(pause: 0.6)

(voice: Matt )
Yes.  
The twists are what make signals in the network cable work reliably.
But for installing the connector , we need to untwist each pair
just enough to straighten the individual wires.

(pause-until: 1:06)

(voice: Matt )
Use your fingers or a small screwdriver to work out the kinks.
Don’t rush—clean, straight conductors make the next steps
much easier and much more reliable.

(pause: 0.8)

(voice: Kirk )
Looks like a lot of fiddling with the wires.

(pause: 0.6)

(voice: Matt )
A little patience here really pays off.
Get each wire as straight as you can.
Sliding each wire between our thumb and the side of a screwdriver works really well to straighten the wires.
If one is still curved or twisted, i t will fight you
when we line them up for the passthrough connector.

(pause-until: 1:40)

When done, do a clean cut of all 8 wires, making them the exact same length.

(pause: 0.8)

(voice: Matt )
And remember—do this on **both ends** of the cable at this time.
If you prepare both ends at the same time,
the whole crimping and testing process goes much smoother.

![](../mp4/Arranging_Wires_part1.mp4)

> **Step 6: Arrange the wires**  
> Place wires into the comb **in color pairs**.  
> Prepare **both cable ends** now.  
> Make sure the wire order **matches on both ends**.  
> Clamp them without shifting.

(voice: Kirk )
Okay, now that the wires are straight — what’s this tool?

(pause: 0.6)

(voice: Matt )
That’s a simple home made jig with a metal comb in it.  
It holds the wires in place so we can arrange them cleanly
without using our fingers.
 
(pause: 0.8)

(voice: Kirk )
So we’re stacking the wires into the comb in a specific order?

(pause: 0.6)

(voice: Matt )
Exactly.  
Load the wires into the same teeth **in color pairs**:
solid blue with stripe blue,
solid orange with stripe orange,
and so on.

(pause: 0.8)

(voice: Matt )
Keeping each pair together preserves the relationship of the twisted pairs
and makes the final alignment easy.

(pause: 0.8)

(voice: Matt )
Now arrange **both ends** of the cable this way.
Whatever order you choose, the two ends must **match exactly**.

(pause: 0.8)

(voice: Kirk )
Does the exact Ethernet order matter here?

(pause: 0.6)

(voice: Matt )
Not for Fusion.  
We use the conductors for digital signals and power,
and some boards even use all pairs for DCC.

(pause: 0.8)

(voice: Matt )
So you’re not following Ethernet standards —
just keep each twisted pair together,
and make sure **both ends match**.

(pause-until: 1:00)

(voice: Matt )
Leave a small gap between the two wire sets in the comb  
so you can clamp them without shifting.
Once clamped, nothing should move.
Any errors will get caught when testing later.

(pause: 0.8)
